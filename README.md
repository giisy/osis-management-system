# OSIS Management System

Aplikasi manajemen OSIS (Organisasi Siswa Intra Sekolah) — full-stack app untuk mengelola anggota, agenda, pengumuman, absensi, kas, inventaris, dan voting internal.

## Tech Stack
- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Node.js, Express, Prisma, PostgreSQL
